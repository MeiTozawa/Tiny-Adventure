## 1. 概要と操作方法

Tiny Adventure は、Unity 6 と URP で制作された一人称視点近接剣戟アクションのプレイアブル Demo です。閉鎖闘技場内で軽装騎士を操作し、NavMesh 経路探索と独立移動モーターを備えた敵と戦います。素早い三段連撃と手応えのある打撃フィードバックに焦点を当てています。

| 操作入力 | キー | 動作内容 |
| :--- | :--- | :--- |
| 移動 | W A S D | 前後左右移動、手持ち武器の歩行呼吸揺れ連動 |
| 視点回転 | マウス移動 | カメラのピッチとヨー操作、武器の慣性追従 |
| ダッシュ | 左 Shift 長押し | 高速走行、武器揺れの振幅と周期が増加 |
| ジャンプ | スペース | 跳躍と重力落下 |
| 剣攻撃 | マウス左クリック | 通常攻撃、連続入力で三段コンボを発動 |
| 設定 | Esc または 画面歯車 | 設定ダイアログ表示、画角とマウス感度を調整 |
| リスタート | R キー | 勝敗決定後のシーン再読み込み |

## 2. コアゲームプレイ設計

### 2.1 一人称ビューモデルと動力学
- **シャドウ専用モデル分離**：プレイヤー三人称モデルは影の投影のみ有効化し、足元に自然な影を落としつつ手元のポリゴンめり込みを防止。手持ち武器は独立したビューモデルカメラで描画。
- **武器の慣性と呼吸ボビング**：マウス回転速度と移動ベクトルを取得し、視点移動時には剣が滑らかに遅れて追従。歩行や走行時には自然なサインカーブで揺動。
- **刀光エフェクト**：攻撃フェーズの推移に合わせて剣先トレイルと発光マテリアルを動的に制御。

### 2.2 三段コンボ攻撃システム
通常攻撃は発生速度、射程、踏み込み距離、威力が異なる三段階の連撃で構成されています：

| 段 | モーション | 威力 | 射程 | 踏み込み距離 | アニメ速度 | 役割と特徴 |
| :---: | :--- | :---: | :---: | :---: | :---: | :--- |
| 第 1 段 | 横薙ぎ | 20 | 2.2m | 0.8m / 0.12s | 1.7x | **素早い初手**：出が早く横の巻き込みが広いため、牽制や間合い調整に最適。 |
| 第 2 段 | 縦斬り | 25 | 2.2m | 1.2m / 0.15s | 1.6x | **中堅破勢**：頭上からの大振り重撃。適度な踏み込みで体勢を崩す。 |
| 第 3 段 | 突進刺突 | 40 | 2.8m | 2.2m / 0.20s | 1.5x | **必殺フィニッシュ**：前方に大きく踏み込む直突き。最長射程、最高威力、強ノックバック。 |

### 2.3 先行入力バッファとコンボ遷移
- **0.25 秒入力バッファ**：前段攻撃の後隙中に左クリックを入力するとバッファに保持され、動作完了の瞬間に遅延なしで次段が発動。
- **0.45 秒コンボ猶予時間**：攻撃終了後 0.45 秒間追加入力がない場合、コンボ段数は自動的に第 1 段へリセット。
- **被撃による中断**：ダメージ硬直、戦闘不能、ジャンプ時はコンボ進行を直ちに初期化。

### 2.4 敵 AI と物理移動の分離
- **総合コントローラーによる一元管理**：`EnemyController` が AI 意思決定（Idle, Chase, Attack）、滑らかな旋回、攻撃判定、被弾ノックバック（`IKnockbackReceiver`）を統括。
- **安全距離制御**：プレイヤー接近時に停止距離 2.1m および攻撃射程 2.35m を保って出刀するため、敵がプレイヤーにめり込んで密着攻撃してくる現象を防止。
- **攻撃タイムアウト保護**：敵の斧攻撃には安全タイマーが配備され、モーション遷移遅延によって判定窓が不意に閉じられる問題を防止。

### 2.5 全体進行と設定の永続化
- **状態管理ゲート**：ゲーム進行管理クラスが勝敗判定を一元管理。終局時は戦闘判定と入力を自動遮断。
- **参照カウント式ポーズ**：`PauseService` により設定画面や UI からの停止要求を一括管理し、物理時間を侵食せずに入力とカーソルロックを制御。
- **ローカル JSON 設定**：画角は 60 度から 100 度、マウス感度は 0.1 から 2.0 まで調整可能で、ローカル JSON ファイルに即座に保存・復元。

## 3. 打撃感の設計

一人称の近接戦闘は手応えが希薄になりやすく、激しい画面揺れは 3D 酔いを引き起こします。本作では 8 つの要素を組み合わせた打撃フィードバックを実装しています：

### 3.1 局所ヒットストップ
命中した瞬間、攻撃者と被撃者のアニメーション速度のみを 0.04 秒から 0.08 秒間停止。全体時間は一切止めないため、背景カメラ、パーティクル、物理挙動は滑らかに動作し続け、刃が肉に食い込む手応えを表現します。

### 3.2 減衰ばねカメラ後仰と照準不変性
被弾時は二階減衰調和振動子モデルでカメラ姿勢を制御：
- **後仰インパルス**：被弾時に頭部が 2.0 度から 3.5 度後ろへ跳ね上がる。
- **被弾側傾**：右から攻撃された場合はカメラが左へ傾き、左からの場合は右へ傾く。
- **瞬間 FOV 圧縮**：被撃瞬間に画角が 2 度収縮し、ばねの反発で自然に復元。
- **照準不変性**：ばねの変位はカメラ描画オフセットとして加算されるのみで、プレイヤーのマウス照準基準角は変更されません。揺れが収まると照準は元の位置へ正確に戻ります。

### 3.3 ビューモデル武器の反動揺れ
攻撃命中時や被弾時、手元の剣が後ろへ 0.03 メートル後退し、下へ 0.04 メートル沈み込みます。ばね物理で素早く元の構えに戻り、武器の重量感を伝えます。

### 3.4 6D インパルス振動
Cinemachine 衝動リスナーを通じて微細な高周波振動を重畳し、頭部の低周波後仰と合わせた立体的な揺れを形成。

### 3.5 方向性物理ノックバック
攻撃ベクトルに沿って敵モーターへ推力を加え、地面摩擦により減速。第 3 段の突き攻撃で大きな吹き飛ばしが発生。

### 3.6 マテリアル発光と火花パーティクル
被撃瞬間にマテリアルシェーダーが 0.08 秒間白く発光。接触面の法線方向に金属火花が即座に飛散。

### 3.7 立体音響とピッチ微動
風切り音、通常打撃音、致命撃破音を個別に再生。命中音の再生ごとに音高をプラスマイナス 5% から 10% ランダムに揺らし、連続攻撃時の聴覚的疲弊を防止。撃破音は 1 戦闘につき 1 回のみ再生。

### 3.8 撃破スローモーション
フィニッシュ命中時または敵撃破の瞬間、全体時間を極短時間 0.2 倍速にしてから滑らかに復帰。

## 4. 企画調整用データアセット

戦闘数値や手応えのパラメータはすべて ScriptableObject アセットにまとめられており、インスペクターで直接調整可能です：

| アセットファイル | 設定内容 |
| :--- | :--- |
| `Assets/Combat/Configs/KnightComboAttackConfig.asset` | プレイヤーコンボ威力、射程、踏み込み推進力・持続時間、アニメーション倍速、判定窓タイミング |
| `Assets/Combat/Configs/EnemyAttackConfig.asset` | 敵近接攻撃威力、有効射程、クールダウン、判定窓開閉タイミング |
| `Assets/Combat/Configs/KnightStatsConfig.asset` | プレイヤー最大体力、移動・疾走速度、ジャンプ挙動パラメータ |
| `Assets/Combat/Configs/EnemyStatsConfig.asset` | 敵最大体力、基本移動速度、旋回速度 |
| `Assets/Settings/CombatFeedbackProfile.asset` | 定格停止時間、画面振動強度、発光持続時間、各種効果音・エフェクトプレハブ参照 |
