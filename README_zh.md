## 1. 项目简介与操作指南

Tiny Adventure 是一个基于 Unity 6 与 URP 开发的第一人称近战冷兵器动作 Demo。玩家在封闭竞技场中扮演轻甲骑士，与具备寻路与独立运动底盘的近战敌人博弈，核心体验聚焦于快节奏剑术连击与扎实的打击反馈。

| 操作输入 | 键位 | 动作功能 |
| :--- | :--- | :--- |
| 移动 | W A S D | 前后左右走位，视口长剑跟随移动呼吸晃动 |
| 观察 | 鼠标移动 | 控制镜头俯仰与旋转，带武器惯性延迟 |
| 冲刺 | 左 Shift 长按 | 快速奔跑，加大视口长剑摆动幅度与频率 |
| 跳跃 | 空格 | 起跳与重力模拟 |
| 挥剑 | 鼠标左键 | 普通攻击，连续输入触发三段连击 |
| 设置 | Esc 或 画面齿轮 | 弹出设置面板，支持调节视场角与鼠标灵敏度 |
| 重启 | R 键 | 战斗结算后重新加载场景 |

## 2. 核心玩法设计

### 2.1 第一人称视口与武器动态
- **双轨阴影分离**：玩家第三人称身体网格开启仅投射阴影模式，低头能看见脚下真实的地面阴影，同时武器由独立视口相机渲染，彻底消除穿模与视线遮挡。
- **武器惯性与呼吸晃动**：捕获鼠标旋转速度与人物位移向量，转动视角时剑身自然滞后跟随，走动与冲刺时按照平滑曲线起伏晃动。
- **刀光与流光表现**：随挥砍动作阶段动态开启与淡出剑刃拖尾及高光发光材质。

### 2.2 三段连击系统
玩家的轻攻击分为三段，各段动作在出刀速度、攻击距离、位移步幅与伤害上均有明确区分：

| 连段 | 动作姿态 | 伤害 | 射程 | 踏步位移 | 动画倍速 | 战术定位 |
| :---: | :--- | :---: | :---: | :---: | :---: | :--- |
| 第 1 段 | 横斩 | 20 | 2.2m | 0.8m / 0.12s | 1.7x | **快速起手**：出刀迅捷，横向范围大，用来试探与先手牵制。 |
| 第 2 段 | 下劈 | 25 | 2.2m | 1.2m / 0.15s | 1.6x | **中坚压制**：大角度纵劈，附带中距离踏步，削减敌人韧性。 |
| 第 3 段 | 突刺 | 40 | 2.8m | 2.2m / 0.20s | 1.5x | **终结斩杀**：长距离踏步直刺，判定距离最长、伤害最高，附加强击退。 |

### 2.3 动作缓冲与连击判定
- **0.25 秒输入缓冲**：在前一次攻击的后摇阶段，提前点击左键会自动存入缓冲队列，前段攻击完成后立即无缝接出下一招，无需精确卡点。
- **0.45 秒连招重置**：一记攻击完成后留有 0.45 秒输入窗口，超时未出刀则自动重置回第一段。
- **受击安全打断**：角色受击硬直、死亡或起跳时，立即清空连招计数。

### 2.4 敌人 AI 与防贴脸机制
- **决策与底盘分离**：敌人大脑负责状态机流转与路径计算，独立运动底盘负责平滑转向、物理位移与受击击退。
- **安全防贴脸间距**：接近玩家时在 1.15 米至 1.8 米范围动态停步出招，避免传统寻路导致的怪物穿进玩家视野贴脸挥砍。
- **挥砍保底超时**：敌人动作切换有 1.5 秒安全计时保护，确保挥斧下落判定完整生效，不会因移动融合过渡被提前掐断。

### 2.5 流程控制与本地设置
- **流程状态机**：由游戏流程控制器统一裁决胜负状态，游戏结束时即刻封锁攻击与伤害入口，杜绝时序死循环。
- **JSON 持久化存储**：游戏视场角支持 60 至 100 度微调，鼠标灵敏度支持 0.1 至 2.0 调节，数据实时存入本地 JSON 文件。

## 3. 打击感设计

第一人称近战最大的痛点是极易产生切空气的虚浮感，而剧烈晃屏又极易造成眩晕。本项目通过八个维度的协同处理，构建了一套分层打击反馈系统：

### 3.1 局域定格（Hit Stop）
命中瞬间仅将攻击者与受击者的动画速度暂停 0.05 至 0.12 秒。关键是不触碰全局时间缩放，背景相机、粒子与物理全速运行，呈现刀刃卡入骨肉而后拔出的扎实质感。

### 3.2 阻尼弹簧受击后仰与瞄准角不漂移
受击时采用二阶物理阻尼弹簧驱动相机姿态：
- **后仰冲量**：受击产生 2.0 至 3.5 度的后仰抬头。
- **受力侧倾**：敌人从右侧砍来则镜头向左侧倾，从左侧砍来则向右侧倾。
- **视场微缩**：受击瞬间视场角瞬态收缩 2 度后自然回弹。
- **瞄准角不漂移**：弹簧偏移仅作为渲染附加层叠加到相机上，玩家真实的鼠标瞄准仰角绝对不被篡改，震荡结束后准星百分之百精确复位。

### 3.3 视口长剑受击震颤
出刀命中或受到攻击时，第一人称手持的长剑会产生向后退 0.03 米、向下沉 0.04 米的物理反冲，并通过阻尼弹簧迅速回正，赋予双手真实的兵器惯性。

### 3.4 6D 冲击波震屏
通过 Cinemachine 冲量监听器叠加高频短促微震，与低频头部后仰相配合，形成立体震动层次。

### 3.5 定向物理击退
命中确认后根据打击向量将推力赋予敌人运动底盘，敌人受击后退并在地面摩擦下平滑减速。第三段突刺带有最强击退推力。

### 3.6 材质闪白与火花粒子
受击瞬间受体材质通过着色器属性闪白 0.08 秒，接触切面沿碰撞法线即刻喷射金属火花粒子，火花飞溅方向与挥刀轨迹严格一致。

### 3.7 空间音频与微扰音高
挥刀破空声、普通命中音与致死终结音分别处理。命中音效播放时随机扰动正负 5% 至 10% 的音高，消除连续出招时的听觉疲倦。死亡音效由独立路由托管，单场战斗每位实体仅触发一次。

### 3.8 战术微缩慢动作
终结技命中或完成击杀时，全局时间短暂下调至 0.2 倍速并维持 0.08 秒，随后平滑恢复常速，营造击溃强敌的定格快感。

## 4. 策划配置资产

战斗数值与手感参数全部存放在 ScriptableObject 资产中，策划可在检视面板直接微调：

| 配置文件 | 负责内容 |
| :--- | :--- |
| `Assets/Combat/Configs/KnightComboAttackConfig.asset` | 玩家三段连招伤害、射程、踏步距离与时间、动画倍速、判定窗口时间点 |
| `Assets/Combat/Configs/EnemyAttackConfig.asset` | 敌人攻击力、攻击距离、冷却时间、挥斧判定窗口 |
| `Assets/Combat/Configs/KnightStatsConfig.asset` | 玩家最大生命值、走跑速度、跳跃高度 |
| `Assets/Combat/Configs/EnemyStatsConfig.asset` | 敌人最大生命值、巡逻与追逐速度、转向角速度 |
| `Assets/Combat/Configs/CombatFeedbackProfile.asset` | 定格时长、震屏强度、闪白时长、音效片段与粒子预制体引用 |
